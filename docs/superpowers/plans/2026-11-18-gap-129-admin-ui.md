# GAP-129 — Admin UI for companies, roles and users: implementation plan

Executes Gate 2 L-1, U-1, R-1, C-1 (`docs/owner-decisions/GAP-129/02-design.md`). Only files in the allowlist change.

1. **Service** `App\Services\Admin\StaffAccountService`:
   - `create(Tenant, email, name, roleName, actor, source)` → `[User, plainPassword]`;
   - `resetPassword(User, actor, source)` → plain password;
   - `changeRole`, `deactivate`, `reactivate`;
   - canonical roles from `ProductionRbacCommand::ROLES`; role must have permissions;
   - email unique;
   - last-active-Owner and self guards (`StaffAccountException` with a Vietnamese message);
   - audit rows via `AuditLog`.
   `ProductionUserCommand` delegates create / reset to it, with unchanged output and audit (CLI `source`).
2. **Red tests** `tests/Feature/Admin/`:
   - `AdminUsersPageTest`;
   - `AdminRolesPageTest`;
   - `AdminCompanyPageTest`;
   - `EnsureUserIsActiveTest`;
   - `AdminLegacyRedirectTest`.
3. **Middleware** `EnsureUserIsActive` appended to the `web` group in `app/Http/Kernel.php`.
4. **Controllers** `App\Http\Controllers\Web\Admin\{UserAdminController, RoleAdminController, CompanyAdminController}`
   with routes under `/app/admin` (names `app.admin.*`).
5. **Views** `resources/views/app/admin/{users,roles,company}.blade.php`:
   - operator layout;
   - table on wide screens, cards on phones;
   - the one-time password panel.
6. **Navigation:** section "Quản trị" (Tài khoản, Vai trò, Công ty), gated by `user.read`.
7. **Legacy:**
   - `/admin/users` and `/admin/tenants` redirect (302) to `app.admin.users` and `app.admin.company`;
   - delete the mock views.
8. **Green;** `ProductionUserCommandTest`; full suite; lints; browser check.
